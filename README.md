# PayroRobot 🤖

Payro is an advanced, AI-powered interactive sales assistant robot built natively for Android using Kotlin. Designed to serve as a virtual or physical store consultant, Payro combines ultra-fast language processing with real-time face detection and natural voice interaction.

## 🌟 Key Features

* **🧠 High-Speed AI Brain:** Powered by the **Groq API** (Llama-3.1-8b-instant) for lightning-fast, context-aware, and logical conversations tailored for sales and customer support.
* **🗣️ Advanced Voice Interaction:** Utilizes **Azure Cognitive Services** for seamless Speech-to-Text (STT) and Text-to-Speech (TTS). Includes custom-engineered **Anti-Echo** and **Barge-in** (interruption) mechanics, allowing users to cut the robot off mid-sentence without audio feedback loops.
* **👁️ Computer Vision & Memory:** Integrates **Google ML Kit** for real-time face detection. Payro can recognize returning customers, read facial expressions (smiling), and adjust its greeting accordingly.
* **🎭 Expressive UI (Vector Style):** Features a custom-built, highly optimized 2D Canvas View (60 FPS) that mimics the "Anki Vector" style. The dynamic glowing neon eyes react to states (Idle, Listening, Speaking) with organic, fluid animations.
* **⚙️ Hardware Ready:** Designed to send physical movement commands (Forward, Backward, Right, Left) to external microcontrollers (like Arduino) via integrated command parsing.

## 🛠️ Tech Stack

* **Language:** Kotlin
* **Platform:** Android SDK
* **AI / LLM:** Groq API (Llama 3.1)
* **Audio Processing:** Azure Speech SDK
* **Vision:** Google ML Kit (Face Detection)
* **Network:** OkHttp3
* **UI / Animations:** Android Custom Canvas & Math functions
